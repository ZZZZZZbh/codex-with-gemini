# Codex 与 Gemini 协作

[English](README.en.md)

让 Codex 通过内置浏览器与 Gemini 协作，完成研究、检索、推导、论文审查及数据或代码分析。Codex 负责执行与最终核验，Gemini 提供独立分析和复核意见。

调用技能后，Codex 会检查 Gemini 当前账号的可用模型和思考设置，选择最高可用能力档位，按任务需要提交已授权的材料，获取实际回复，再与自身分析和原始证据交叉核对。

## 功能

- 实时检查模型菜单与思考等级，使用当前可用的最高档位，不固定某个模型版本。
- 按任务范围上传相关文件和数据，分别核对上传状态、内容读取和实际覆盖范围。
- 获取完整回复，围绕公式、来源、数据或分歧继续追问。
- 对照 Codex 的独立检索、推导、计算和测试，按证据处理双方分歧。
- 保持材料版本、来源和必要的协作记录可追溯。
- 登录失效时交由用户在浏览器完成认证，恢复后继续工作。

## 运行条件

当前 Codex 会话需要具备浏览器 UI 操作能力，并能访问 Gemini 网页。上传功能还需要宿主提供文件选择器接口。Gemini 账号的订阅、剩余额度及实际菜单决定可用模型与思考档位。

浏览器控制能力由宿主环境提供；本仓库提供技能指令、界面元数据和操作细则。用户在自己的浏览器中登录自己的 Gemini 账号。

## 安装

推荐在 Codex 中使用内置的技能安装器：

```text
使用 $skill-installer，从 https://github.com/ZZZZZZbh/codex-with-gemini
安装 skills/codex-with-gemini。
```

也可以下载或克隆仓库，将 `skills/codex-with-gemini` 整个文件夹复制到当前客户端读取的个人技能目录。

当前官方文档列出的个人目录为 `~/.agents/skills`，项目目录为 `.agents/skills`。部分客户端使用 `~/.codex/skills`；应以当前客户端的实际技能目录为准，保留一个同名安装位置。安装后在技能列表中确认 `codex-with-gemini`，必要时重新启动客户端。[官方技能文档](https://learn.chatgpt.com/docs/build-skills)

## 使用

```text
使用 $codex-with-gemini，检索并比较这个研究方向的主要方法，
核验关键文献，给出双方意见和最终判断。
```

```text
使用 $codex-with-gemini，复核我指定文件中的理论推导。
按需要上传相关材料，给出分歧、核对证据和修改建议；本次只审查。
```

```text
使用 $codex-with-gemini，审查这个算法方案，并由 Codex
结合实际代码和测试核对 Gemini 的建议。
```

技能主体使用简体中文。任务中可以指定输出语言、材料范围、只读审查或其他要求。

## 协作流程

1. Codex 明确问题、材料版本和核验点，并形成独立分析。
2. 检查 Gemini 的可用模型及最高思考档位，确认页面选中状态。
3. 提交任务和必要材料，验证附件读取，等待完整回复。
4. 针对关键分歧追问，并回到原文、公式、数据或实际运行结果核验。
5. 交付研究结果，并简要记录实际模型、材料范围和采用结论的依据。

模型设置以网页选中状态为依据；网页提供回复详情时，进一步检查本轮实际生成模型。额度或权限发生变化时，说明实际采用的配置。

## 文件与登录信息

技能文件包含工作流程、通用网址和浏览器操作示例。账号密码、验证码、API Key、Cookie 和登录令牌由使用者自行管理，不属于技能内容。

上传以当前任务指定或明确授权的材料为范围。研究文件、浏览器配置、截图和对话记录应保存在使用者自己的工作目录中。提交 issue 或 PR 时，请先检查其中是否含有个人信息或私有材料。

## 本地验证方法

可让 Codex 创建两份合成 TXT 文件：一份包含随机测试标识与问题，另一份包含数据和另一个随机标识。先在本地保存参考结果，再上传文件，请 Gemini 返回标识、结果和必要推导。

一个可复现的数据案例是：时间为 `0、2、5、9、10 s`，功率为 `0、12、6、4、0 W`，相邻点之间按线性变化处理。参考结果为逐段能量 `12、27、20、2 J`，总能量 `61 J`，时间平均功率 `6.1 W`，样本算术平均值 `4.4 W`。

检查附件标识与数据是否准确、回复是否完整、数值与单位是否一致，并保留当前环境下的实际结果。仓库发布内容采用通用技能与说明文件，本地运行记录由使用者保存。
